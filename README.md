# Mists of Pandaria 5.4.8 (Build 18414) Private Repack

This repository contains the source code and custom database patches for a private Mists of Pandaria 5.4.8 repack.

It is based on [alexkulya/pandaria_5.4.8](https://github.com/alexkulya/pandaria_5.4.8) and includes additional source changes, database fixes, and Korean localization work.

## Downloads

- **Repack Data folder:** [Download](https://naver.me/GntbHFpb)
- **Full game client:** [Mists of Pandaria 5.4.8 (18414).zip](https://xgf.nu/2j4ts) — 20 GB

The client download link is available until **Thursday, December 3, 2026**.

## Repository Contents

- Modified server source code
- Custom repack database patches
- Korean integrated SQL patch managed with Git LFS

Large runtime files, the game client, MySQL data, backups, logs, and private credentials are not included in this repository.
